# Google Material Symbols Rounded sources

The included official SVG assets are copied unchanged from Google's public google/material-design-icons repository at commit 10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7.

- Official repository: https://github.com/google/material-design-icons
- Rounded SVG directory: https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web
- Catalog: https://fonts.google.com/icons — select Material Symbols, then Rounded
- Asset path pattern: symbols/web/{name}/materialsymbolsrounded/{name}_24px.svg
- License: Apache License 2.0; the complete license text is included as Apache-2.0-LICENSE.txt.

No BitchPixel glyphs are created, edited, combined, or used as substitutes in
this package. It contains the approved mappings in `icon-map.csv` plus official
Material Symbols used for common interface affordances. Keep local vector assets,
pin their source commit, and do not require Google Fonts or network access at
runtime.

Google's repository README says attribution is welcomed but not required. BitchPixel should preserve source/asset provenance in its third-party notices and include the Apache license and required notices. This package makes no use of Google's logo or wordmark.
