# Material Symbols Rounded assets

The toolbar uses official Google Material Symbols Rounded SVGs copied byte-for-
byte from `google/material-design-icons` at commit
`10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`. The approved tool mapping is
preserved in `icon-map.csv`. The package also includes official symbols used for
common interface affordances. `MATERIAL-SYMBOLS-SOURCE.md` records upstream
provenance, and `Apache-2.0-LICENSE.txt` contains the license.

Each SVG is bundled beside a 96 × 96 transparent PNG mask generated by
`scripts/render-material-symbols.py`. The PNG retains only the source symbol's
coverage and egui applies the current theme color. The checked-in masks mean
application builds and runtime do not need Inkscape, a rasterization dependency,
Google Fonts, or network access. SVG and PNG SHA-256 values are recorded in
`manifest.json`.
